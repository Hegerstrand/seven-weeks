# Extension: The Wolf Returns

**Track:** B - additive.

**Requires:** the base game (rulebook v0.33 or later), which already contains the Events
**EVERYONE IS EQUAL** and **THE WOLF** (§11). **Changes:** THE WOLF is no longer a one-off. It
comes back, and each time the team pays more to keep its shepherd.

**Status: drafted 2026-10-09, never played.** Every number below is a first guess.

## Why this pack exists
In the base game THE WOLF is one card in 25, drawn in about half of all games, answered once.
That tests whether the team will pay for its shepherd, but only once, and a team can budget for
a single Motivation point. The Nietzsche/Foucault reading behind the card (see
`docs/theoretical-sources.md`) is about something slower: a flock that is gradually taught it
has no shepherd and does not need one. This pack makes that pressure repeat, and makes the
price of resisting it grow.

## What this pack changes
1. **THE WOLF is shuffled back, not discarded.** After it resolves (either way), shuffle it back
   into the Event deck. It can be drawn again.
2. **Stepping up costs more each time.** Count the times the team has stepped up against THE
   WOLF this game. The next time it is drawn, stepping up costs every character
   **1 Motivation + 1 for each earlier step-up** (so 2, then 3). A team that let its shepherd
   fall does not pay extra later: the Wolf found that out already.
3. **The next shepherd.** A character whose Capital was set to 0 by THE WOLF is no longer the
   one with the most Capital, so the next time it is drawn it takes whoever is highest then.
   If nobody holds more than 0 Capital, discard it for good (nobody is worth taking).

Nothing else changes: it still cannot be cancelled (no tokens, no Hero, no Authorized Voice).

## Components needed
- A **step-up counter** (a tally on THE TEAM board, or any spare token pile). Not yet designed.

## Open questions
- Does the escalating cost make the team stop stepping up after the second time, and is that
  the interesting outcome (a team that learns to let go) or just a punishment?
- Should EVERYONE IS EQUAL also repeat (Authorized Voice stays off until an Engagement is
  played)? Not in this draft - one escalating pressure is enough to test first.
- Is "shuffle it back" too much, given the 12-of-25 draw? Alternative: put it back only if the
  team stepped up, so a team that lets the shepherd fall is left alone.
